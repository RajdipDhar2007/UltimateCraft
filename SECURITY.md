# Security policy

UltimateCraft is an offline single-player game: it opens no network connections and collects no data
(see [PRIVACY.md](PRIVACY.md)). The realistic attack surface is a **malicious save, data pack or language file**
that crashes or corrupts the game.

If you find such a problem, please report it privately through GitHub's *Security → Report a vulnerability*
form on this repository instead of opening a public issue. Include the file that triggers it and the version
shown on the title screen.
