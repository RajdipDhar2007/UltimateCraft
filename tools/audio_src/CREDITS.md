# Sound credits

Every sound in UltimateCraft is built from real recordings. The game's own code only transposes, trims, layers, filters
and adds reverb (`tools/build_audio.py`, recipes in `tools/audio_recipes*.py`); the results are the Ogg Vorbis files in
`res/audio/`. All source material is **public domain, CC0, or CC BY** (attribution given below). Nothing is taken from
any commercial game.

Thank you to every author below for sharing their recordings.
