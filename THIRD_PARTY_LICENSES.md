# Third-party licences

UltimateCraft is written from scratch in C. It bundles the libraries below (in `lib/`); their licences require these
notices to ship with the game. Every texture, model and piece of music is generated by the game's own code; no
third-party art is included. **Sound effects and creature voices are built from real recordings** that are public
domain, CC0 or CC BY - the full author credits and licences are in [`tools/audio_src/CREDITS.md`](tools/audio_src/CREDITS.md)
and the processed files are in `res/audio/`. The optional developer tools in `tools/` use the Python packages Pillow,
NumPy, SciPy, matplotlib and ffmpeg (via imageio-ffmpeg) at development time only; none of them is bundled with or needed to run the game.

| Library | Use | Licence |
|---|---|---|
| GLFW 3 | windows, input, OpenGL context | zlib/libpng |
| glad 0.1.33 | OpenGL function loader (generated code) | generator MIT; `khrplatform.h` Khronos licence (below) |
| cglm | vector / matrix maths headers | MIT |
| stb_image (Sean Barrett) | PNG loading/writing | MIT or public domain (your choice) |
| stb_vorbis (Sean Barrett) | Ogg Vorbis decoding of the sound files | MIT or public domain (your choice) |
| noise1234 (Stefan Gustavson) | Perlin noise | public domain |
