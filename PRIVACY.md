# Privacy

UltimateCraft does not collect, send or share any personal data.

* **No network traffic.** The game never connects to the internet: no accounts, no telemetry, no analytics, no ads.
* **Local files only.** Worlds (`saves/`), settings (`settings.txt`), screenshots (`screenshots/`) and, if the
  game crashes, `crash.log` are written to the game folder on your computer and stay there.
* **Crash logs** contain a stack trace of the game code and a time stamp – no personal information. They are
  only ever sent anywhere if *you* attach them to a bug report. (An opt-in automatic crash reporter is planned; it
  will be off by default and will ask before sending anything.)
* **Data packs** you install run only inside your worlds and cannot access the network.

Questions: contact the publisher listed on the store page.
